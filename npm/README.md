# cite-caddy

This npm package name is reserved for **Cite Caddy** -- a remote MCP
(Model Context Protocol) server bridging AI assistants to a Zotero
library, built on the Zotero Web API. Independent, unofficial project;
not affiliated with Zotero.

No published code lives here yet. The current implementation is a
Python server -- see the [repo root](../) and
[README.md](../README.md).

Site: https://citecaddy.com
